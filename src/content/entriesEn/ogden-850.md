## About the project

Ogden 850 is an English expression trainer based on the idea of Basic English. Rather than memorising a large vocabulary at once, it builds a set of basic words you can actively use through a small number of high-frequency words, combinations of meaning and repeated practice.

## Features

- Browse and search the 850 basic words
- Filter by categories such as operators, things, qualities and properties
- View phonetics, Chinese glosses, simple definitions and example sentences
- Flashcards, multiple choice and spelling practice
- Save words, and track progress and mistakes
- Data and learning records stay in the current browser only

## Design notes

This is an independent implementation of the public site’s features; it does not copy the original page code. The word data is used to build a local English learning tool you can use directly on this site.
